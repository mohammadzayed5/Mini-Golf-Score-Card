# Printable Mini Golf Scorecard (and a faster way)

Here is a free printable mini golf scorecard you can copy into a doc, size to a quarter sheet, and take to the course. There's a 9-hole version and an 18-hole version below, plus a note on when paper is fine and when it stops being fine (usually around hole 11, when the wind picks up).

## The 9-hole scorecard

Copy this into Google Docs or Word, shrink the font to about 10pt, and print two per page. You want it small enough to fit in a back pocket without folding weirdly.

```
MINI GOLF SCORECARD: 9 HOLES
Course: ______________________  Date: _________

Player          | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | TOTAL
----------------|---|---|---|---|---|---|---|---|---|------
                |   |   |   |   |   |   |   |   |   |
                |   |   |   |   |   |   |   |   |   |
                |   |   |   |   |   |   |   |   |   |
                |   |   |   |   |   |   |   |   |   |

Par (if posted): ____   Winner: ____________________
```

Four rows fits most family groups. If you have five or six players, add rows. Nothing about mini golf breaks if you have seven people, except your patience on hole 3 while everybody figures out the windmill.

## The 18-hole scorecard

Same idea, wider. If you print landscape you can keep the columns roomy enough to write in without cramping.

```
MINI GOLF SCORECARD: 18 HOLES
Course: ______________________  Date: _________

              | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | OUT |10 |11 |12 |13 |14 |15 |16 |17 |18 | IN | TOTAL
--------------|---|---|---|---|---|---|---|---|---|-----|---|---|---|---|---|---|---|---|---|----|------
              |   |   |   |   |   |   |   |   |   |     |   |   |   |   |   |   |   |   |   |    |
              |   |   |   |   |   |   |   |   |   |     |   |   |   |   |   |   |   |   |   |    |
              |   |   |   |   |   |   |   |   |   |     |   |   |   |   |   |   |   |   |   |    |
              |   |   |   |   |   |   |   |   |   |     |   |   |   |   |   |   |   |   |   |    |
```

The OUT and IN columns are the front-nine and back-nine subtotals. They exist so you can add nine small numbers instead of eighteen. Your brain will thank you at hole 18 when someone's arguing about whether Dad's 7 was really a 7 or a "generous 6".

## Print settings that hold up in the wild

Some settings that sound picky and matter a lot after ten holes in a windy parking lot:

- **Card stock, not printer paper.** 65 lb card stock (the cheap stuff at any office store) survives a folded pocket and a light drizzle. Regular 20 lb printer paper turns into confetti.
- **Print two per page and cut.** A full 8.5 by 11 sheet flapping in the wind on the tee mat is a comedy sketch. Half-sheet is the friendly size.
- **Bold the header row.** When someone borrows your card at hole 7 to confirm which column is theirs, a bold header line is worth the two seconds of formatting.
- **Fold in half, then in quarters.** It fits in a back pocket and the corners don't fray by hole 12.
- **Bring a spare.** Two cards weighs nothing. If the first one goes airborne, the round doesn't stop.

## How to fill it in without regretting it later

A few things that sound obvious and are absolutely not, based on every family round ever played:

1. **Write player names before you leave the car.** The tiny pencil the course gives you is not the tool for handwriting three names in a breeze.
2. **Score after each hole, at the hole.** Do not "remember it and write it down at hole 4". You will not remember it.
3. **Circle disputed scores.** If Dad insists it was a 5 and everyone else saw a 6, circle it and move on. You can litigate later.
4. **Cap the hole.** Most courses cap scores at 6 or 7 strokes so nobody spends fifteen minutes on the loop-de-loop. Pick a cap before you start.
5. **Add subtotals at hole 9 and hole 18.** If you wait until the end, you're adding eighteen numbers with a stubby pencil while a kid tugs on your sleeve. That's its own punishment.

## When paper is fine, and when it isn't

Paper works when it's a calm afternoon, one round, three people, and you're going straight to the car afterward. It's charming. The tiny pencil is part of the experience.

Paper stops working when: it's windy and the scorecard wants to become a kite, you've got an 8-year-old with an oversized putter who cannot be trusted with the pencil, someone's hands are wet from the water hazard, you play multiple rounds and want to track who's won across visits, or you have more than four players and the rows get cramped.

That last one is where most families give up on the printable. Five kids, one scorecard, a sticky pencil. You end up with scores in the margin and someone crying at hole 12.

## A quick note on par

Most mini golf courses post a par of 2 or 3 per hole. You don't strictly need par written on your scorecard to play; you just need the stroke counts. If you want to track over/under par, write the course's par row at the top and do the math at the end. Or don't. Lowest total wins is a perfectly good rule.
